Reference

Performance basis

Cloud Dry is The Cushion Store’s branded open-cell reticulated outdoor foam. The ranges on the Technical Story are engineered targets grounded in published open-cell reticulated and antimicrobial polyether technical data sheets. They are not lot-specific ASTM certificates.

Customer-facing product language uses Cloud Dry exclusively. Industry datasheets in this class are sometimes filed under other generic path names; those URLs are listed as published.

Open-cell reticulated class

  • Foam Factory outdoor reticulated TDS — density, ILD, airflow ≥20 CFM, antimicrobial, 50% compression set ceiling
  • FoamOnline outdoor reticulated class
  • Federal Foam reticulated medium — 1.7–1.9 pcf; outdoor cushion use
  • Urecel QuickDry grade bands

~1.8 pcf HR / antimicrobial polyether

  • Federal Foam 1.8# antimicrobial polyether — 25% IFD 32–40; 50% compression set <10%
  • PFA InTouch — ASTM D3574 method context

Densified polyester batting (commodity)

  • Cushion Pros filling types — densified fiber density 1.75–1.85; IFD 21–29 lb

Metrics that remain laboratory-pending: lot-specific ASTM D3574 certificates; composite-sandwich compression set; quantitative batting CFM. OEM dimensions and COM yardages are not pending — they come from the customer brief and appear in the Fit Tool.
